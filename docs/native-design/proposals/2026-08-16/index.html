B · During Run — cadence in the secondary row, position marker + recenter, Lap control

Matches 03-during-run.png: secondary row becomes Cadence · Elevation · Calories (moving time moves to the summary/detail where it already is). The map gets the approved position marker (primary ring dot) plus a 44 dp recenter control that appears only after the runner pans. The left control slot — the mock's Lock, which is NATRUN-07 — carries Lap for now, in the same 48 dp circle language as Finish. Cadence is live: steps over a rolling ~20 s window, "—" until the window has enough valid samples or while stopped; the whole-run average stays on the summary and details.
